# 潮汐Mini 主界面适配调整

## 目标与范围
修正已确认的主界面按钮文本偏移及卡片底部空白；沿用当前原生 Java View、背景、颜色和功能。只调整布局，不改闹钟规则。

## 已确认原因
- SleepActivity.build 给卡片固定 570dp 高度，ScrollView 内容不填满；移除设置按钮和说明后仍保留旧高度，空白留在卡片内。
- SleepUi.icon 只设置左侧 compound drawable；TextView 居中文字在扣除左图标的区域中居中，造成文字向右偏，图标与文字距离随按钮宽度扩大。
- 主界面用整屏 displayMetrics 高度减固定 140dp；未依据实际内容窗口测量，分屏和横屏的适配依据不准确。

## 采用方案
1. 卡片以实际内容高度为准，使用 wrap_content；超过可用高度才滚动。保留底部 18dp 内边距，不用固定高度填充。
2. 卡片在工具栏下方的实际可用区域居中，宽度不超过 480dp，左右至少 16dp；顶部为设置按钮保留 72dp。手机、平板使用同一单列内容逻辑，分屏按当前窗口尺寸测量。
3. 图标嵌入文字旁，图标与文字固定间距，并在文字另一侧留等宽透明占位，使所有按钮的文字中心线一致。长按进度图标使用同一绘制对象，保留既有计时与取消行为。
4. 小窗口或大字体情况下卡片滚动，按钮不使用权重拉伸；不改变系统显示尺寸/字体设置。

## 不采用
- 单纯把 570dp 改成另一个固定值：只能适配当前设备。
- 把所有按钮拉高填满：放大视觉噪声，小屏更容易挤压。
- 平板改双栏：本次内容不需要，扩大改动范围。

## 执行与验收
- 修改 SleepActivity 主界面容器及 SleepUi 图标排版；同步保留长按圆环。
- 运行 python3 潮汐/TideRebuild/scripts/test.py 与 scripts/build_offline.py。
- 在已授权 ADB 设备覆盖安装并截图，检查文本中心线、图标间距、卡片底部和滚动行为；设备锁屏需用户解锁时明确记录限制。
- 适配检查以实际可用窗口为准；没有设备验证的窗口尺寸不声称已真机通过。

## 执行结果
已实现并构建为 0.4.1-mini（versionCode 7），安装到当前 ADB 设备并检查截图。主界面内容居中、卡片高度随内容、按钮文字中轴一致。核心测试通过。真机证据位于 `潮汐/analysis/mini-v041-device/home-installed.png`。其他窗口及大字体未做实际设备验证。设备安装异常及当前权限状态详见工程 VALIDATION.md。
