# 潮汐睡眠闹钟与声音恢复

## 目标与范围
将 TideRebuild 更新为睡眠闹钟与后台声音应用，隐藏专注/呼吸/记录入口。尽可能复用 APK 内睡眠美术与原版布局；不录音、不做呼吸/睡眠分析，不接云端账户。

## 实现边界
包名仍为 io.moreless.tide.rebuild，不覆盖 io.moreless.tide。保留旧源文件和旧交付包。默认单次次日闹钟，支持取消与稍后提醒；具体 UI 依据原始资源。精确闹钟由 AlarmManager.setAlarmClock 调度，播放由前台媒体服务负责；持久化会话，恢复系统回收/重启后的已设闹钟。强行停止、权限撤销、厂商禁止自启动不承诺绕过。不开麦、不请求应用列表/悬浮窗。

## 执行
1. 核对原睡眠 UI、资源、原生闹钟调度，读取官方 Android 权限/后台约束。
2. 先写闹钟时间与状态恢复测试；实现调度器、接收器、响铃/稍后提醒和持久状态。
3. 更新播放服务，保障锁屏播放和必要的进程恢复；提供精确闹钟/通知/后台电池设置入口。
4. 原版素材复用与睡眠首页/声音选择/响铃页面重建。资源使用独立溯源表。
5. 构建、独立代码审查、独立包真机检查：短时测试闹钟、取消、稍后提醒、锁屏后台播放、应用进程恢复。危险/破坏性或原版数据操作不执行。
6. 新版本 APK 和源码包，更新功能/限制及验证记录。

## 验收
只呈现睡眠、声音和必要设置；实际调度可核验；取消旧闹钟不留残余；已暂停不自动恢复播放；闹钟能在进程不在时触发；闹钟时刻与时区/DST 使用日历算法；重建会话不重复响铃。区分代码测试、实际设备结果与未验证的极端后台场景。


## 本轮结果
0.2 工程与 APK 已实现并编译；旧入口禁用、原睡眠美术复用、系统闹钟、稍后提醒、取消与前台播放持久意图已完成。用户在公司后改为无声验证。正常闹钟触发获用户确认；静音进程退出后系统拉起闹钟和重新调度/取消已核对。静音全屏在当前设备未自动弹出，保留限制；整夜、重启、深度 Doze 未验证。详见 TideRebuild/VALIDATION.md。
